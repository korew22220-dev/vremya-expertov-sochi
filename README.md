# Время Экспертов — Сочи

Многостраничный сайт салона красоты, косметологии и SPA. Статические файлы находятся в `dist/`. Главная страница — `dist/index.html`. Дизайн, цены и изображения включены в проект; запись ведёт в DIKIDI.

## GitHub Pages

Workflow `.github/workflows/pages.yml` при пуше в `main` готовит файлы командой `python export_pages.py` и публикует `_site` через GitHub Pages. В настройках репозитория Pages нужно выбрать **GitHub Actions** как источник публикации.

Адрес после запуска Pages: https://korew22220-dev.github.io/vremya-expertov-sochi/

Прайс и фотографии взяты из карточки организации в Яндекс Картах (срез на 29 сентября 2026). Для изменения цен обновите страницы в `dist/` и отправьте коммит. Перед коммерческим использованием фотографий проверьте права у салона.
